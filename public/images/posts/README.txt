HOW TO ADD IMAGES TO BLOG POSTS
================================

1. Add your image file here (JPG or PNG recommended)
   - Ideal size: 1200 x 630 px (same as og:image ratio)
   - Keep file size under 200KB for fast loading
   - Name it the same as your post file:
     Post file:  content/posts/best-ai-tools-usa.md
     Image file: public/images/posts/best-ai-tools-usa.jpg

2. In your post's frontmatter, add the image field:
   ---
   title: "Best AI Tools for Small Business USA 2026"
   description: "..."
   date: "2026-05-01"
   category: "AI Tools"
   image: "/images/posts/best-ai-tools-usa.jpg"
   ---

3. Push to GitHub — image shows automatically on the card.

If no image is set, the card shows a color gradient automatically (no action needed).

FREE SOURCES FOR BLOG IMAGES (no license issues):
- https://unsplash.com  (free high quality photos)
- https://pexels.com   (free photos)
- https://pixabay.com  (free photos & illustrations)

Always search "technology", "laptop", "software", "business" etc.
